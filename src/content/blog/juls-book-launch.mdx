# first steps
below you can find some features that will be integrated into the site

# MUST-HAVE (Launch-ready)
| Feature | Why it matters | Quick implementation |
| :------ | :---: | ----: |
| **Clean homepage with hero** | First impression; instantly tells visitors *who, what, book title, cover, tagline*. | Full-width cover image + 1-sentence hook + “Buy Now” CTA buttons. |
| **Book synopsis / blurb** | Hooks browsers into buyers. | 150–250 word back-cover text + pull-quote. |
| **Buy links (universal link or multiple retailers)** | Frictionless purchase = sales. | Buttons for Amazon, Apple Books, B&N, Kobo, Bookshop.org, indie bookstore, signed copy form. Use a service like **Books2Read** or **Genius Link** for one URL → all stores. |
| **Author bio + photo** | Builds trust & connection. | 100-word bio, professional headshot. |
| **Contact / newsletter sign-up** | Capture emails for launch & future books. | Embedded Mailchimp/ConvertKit/Substack form; offer a **reader magnet** (short story, deleted chapter PDF). |
| **Mobile-responsive design** | 60% + traffic is mobile. | Use any modern theme (WordPress Astra, Webflow, Carrd, Squarespace). |
| **Basic SEO** | Google discoverability. | Page title: “*Book Title* by *Author Name* – [Genre]”; meta description = blurb; alt text on images; submit to Google Search Console. |
| **Social proof** | Credibility. | Early reviews, “As seen in…”, Goodreads widget. |
