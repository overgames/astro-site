# About
My friend Julian is launching a site for his new book. we have a scheduled launch for next Friday (11/21). until then, here are some logs related the project!

# First Steps...
What features will we include? Here are some features that we intend to have on launch:

## Must-haves. (Launch-ready features.)
| Feature | Quick implementation |
| :------ | ----: |
| **Clean homepage with hero** | Full-width cover image + 1-sentence hook + “Buy Now” CTA buttons. |
| **Book synopsis / blurb** | 150–250 word back-cover text + pull-quote. |
| **Buy links (universal link or multiple retailers)** | Buttons for Amazon, Apple Books, B&N, Kobo, Bookshop.org, indie bookstore, signed copy form. Will use a service like **Books2Read** or **Genius Link** for one URL → all stores. |
| **Author bio + photo** | 100-word bio, professional headshot. |
| **Contact / newsletter sign-up** | Embedded Mailchimp/ConvertKit/Substack form; may offer a **reader magnet** (short story, deleted chapter PDF). |
| **Mobile-responsive design** | Use any modern theme (WordPress Astra, Webflow, Carrd, Squarespace). |
| **Basic SEO** | Page title: “*Book Title* by *Author Name* – [Genre]”; meta description = blurb; alt text on images; will submit to Google Search Console. |
| **Social proof** | Early reviews, “As seen in…”, Goodreads widget. |
